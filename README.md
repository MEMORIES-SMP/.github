# MEMORIES

> Build something worth keeping.

MEMORIES is a Minecraft SMP project focused on meaningful progression, a fair player-driven economy, and a polished server experience that feels coherent from the first join to the endgame.

[Website](https://msmp.juwenn.top) · [Discord](https://discord.gg/f6TAD6Ztug) · [Minecraft project](https://github.com/MEMORIES-SMP/MemoriesPlugin-SMP)

## What we build

- A survival experience where exploration, farming, combat, and community all matter.
- A transparent economy with shop, player marketplace, transaction history, and safeguards against common exploits.
- Configurable quests with chat and action objectives, so the progression can evolve without recompiling the plugin.
- A premium, consistent visual identity across the server, resource pack, user interface, chat, and documentation.
- Practical operations tooling for moderation, permissions, localization, backups, and server maintenance.

## Design principles

- Progress should feel earned, not automated.
- Prices and rewards should support activity without making survival meaningless.
- Important actions should be auditable and recoverable.
- Configuration belongs in readable files whenever possible.
- The default experience is English, with Bahasa Indonesia available for players who prefer it.
- Every feature should serve the identity of Memories instead of making the server feel like a pile of unrelated plugins.

## For contributors and administrators

The public organization page contains project direction and documentation. Server source, credentials, player data, and operational configuration are kept private.

Before making a change:

1. Read the relevant documentation in [Wiki-SMP](https://github.com/MEMORIES-SMP/Wiki-SMP).
2. Keep secrets, live server data, and personal credentials out of commits.
3. Prefer configuration changes for prices, quests, messages, and other tunable content.
4. Build and test locally before deploying to the live network.
5. Record behavior changes clearly so the next administrator can maintain them.
